3. External Standards & Liaisons

External Standards Bodies & Liaisons — Not W3C Groups

Several rows in the main crosswalk reference terminology or protocols that are governed outside W3C. These are not part of the W3C group landscape but come up repeatedly enough in the AI-agent CGs' charters and coordination notes to warrant a standing reference list.

IETF WIMSE (Workload Identity in Multi System Environments)

Referenced by: Agent Identity Registry Protocol CG (anticipated coordination). Governs workload/service identity patterns relevant to agent-to-agent authentication. https://datatracker.ietf.org/wg/wimse/about/

Model Context Protocol (MCP)

Referenced by: AI Agent Memory Interoperability CG (explicitly out-of-scope, deferred to MCP for tool-routing semantics). Not an IETF or W3C standard — governed by Anthropic and an open contributor community. https://modelcontextprotocol.io

OpenID Foundation AIIM (AI Identity Management) Working Group

Referenced by: Agent Identity Registry Protocol CG (anticipated coordination), alongside NIST's AI Agent Identity initiative. Governs OIDC-based identity patterns for AI agents. https://openid.net/wg/aiim/

Decentralized Identity Foundation (DIF)

Referenced by: Agent Identity Registry Protocol CG (anticipated coordination). Maintains DID method registries and interoperability profiles complementary to W3C DID/VC work. https://identity.foundation

NIST AI Risk Management Framework (AI RMF 1.0) / NIST AI Agent Identity initiative

Referenced by: AI Agent Memory Interoperability CG and AIVS CG (regulatory crosswalks); Agent Identity Registry Protocol CG (identity initiative). https://www.nist.gov/itl/ai-risk-management-framework

ISO/IEC 42001:2023 (AI management systems) and ISO/IEC 27001:2022 (information security)

Referenced by: AI Agent Memory Interoperability CG, AIVS CG — both cite these as regulatory/compliance crosswalk targets for audit-trail and lifecycle vocabulary.

EU AI Act (Regulation 2024/1689)

Referenced by: AI Content Disclosure CG (Article 50, content-disclosure obligations); AI Agent Memory Interoperability CG and AIVS CG (Article 19, audit-trail obligations).

4. Notes & Methodology

W3C AI / Agentic-AI Vocabulary Crosswalk — Notes & Methodology (v2)

Purpose

Compiled to support AIKR CG alignment work across current W3C Working Groups, Community Groups, and the one relevant Interest Group whose scope touches AI or agentic AI, ahead of formal cross-group vocabulary reconciliation.

What changed in this revision

Following an internal review, this version: (1) separates maturity stage from raw participant counts into their own columns; (2) splits spec links into Published / Draft / Planned so shipped work is never conflated with charter aspirations; (3) standardizes group-type and maturity-stage vocabulary across all rows; (4) tones down evaluative language ('largest', 'natural convener') into sourced, qualified statements; (5) adds a Foundational Vocabulary Groups sheet (Credentials CG, Verifiable Credentials WG, JSON-LD CG, Web of Things WG, Schema.org) that most agent-identity and agent-metadata proposals implicitly depend on; (6) adds an External Standards & Liaisons sheet for IETF/OpenID/DIF/NIST/ISO/EU AI Act references that recur across group charters but sit outside W3C process; (7) expands cross-link notes to explicitly name overlapping groups in both directions.

Maturity-stage vocabulary used throughout

Proposed | Incubation (early) — chartered within roughly the last year, few or no published deliverables | Incubation (active) — established, ongoing deliverable production | Recommendation-track (WG) — chartered Working Group short of full Recommendation | Recommendation / Maintenance — shipped W3C standard | Coordination forum (IG) — Interest Group, does not produce Recommendation-track specs | External dependency — governed outside W3C entirely.

Scope & method

Groups were identified by cross-referencing the W3C current-groups directory (w3.org/community/groups/, w3.org/groups/wg/, w3.org/groups/ig/) against AI/agent-related keywords, then verified individually via each group's home page, charter, and (where available) GitHub repository, as of 16 July 2026. Participant/organization counts are sourced from each group's own participants page and are timestamped to that page's last update, not to this document's compilation date — they will drift.

Outstanding verification items (unresolved as of this revision)

Confirm whether Agent Trust Protocol CG, AI Agent Memory Interoperability CG, ADORAI, Context Graphs CG, and AI Content Disclosure CG have published GitHub repositories since this review (several are marked 'not yet confirmed').

Confirm whether the AIKR CG-to-Working-Group transition discussed at TPAC 2025 has since been formally proposed or chartered.

Confirm current chair/participant status for Human Centric AI CG, whose public activity is largely off-W3C.

Re-verify Web of Things WG's charter end date (listed as 2 April 2026 on its group page at time of research) before citing it as an ongoing active group.

Suggested next steps for AIKR

1. Convene the three converging identity/trust efforts — AI Agent Protocol CG, Agent Trust Protocol CG, and Agent Identity Registry Protocol CG — around the existing W3C Credentials CG / Verifiable Credentials WG vocabulary, rather than letting each independently define DID and credential terms.

2. Open direct contact with Context Graphs CG — the closest philosophical overlap with AIKR's own mission (semantic alignment across knowledge models) of any group surveyed.

3. Use WebAgents CG's own charter language (naming AIKR as an appropriate home for AI-specific vocabulary) as the citable mandate when proposing a formal crosswalk exercise.

4. Propose the crosswalk as a joint deliverable through the Web & AI Interest Group, which already carries a cross-group landscape-tracking mandate in its charter.

5. Anchor any new AIKR vocabulary in JSON-LD serialization conventions and, where applicable, Schema.org types, rather than defining a parallel metadata format.
